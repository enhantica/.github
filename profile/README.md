# enhantica

data, and the small, sharp utilities that grow around serious software work.

The flagship projects are in **active early-stage development** and not yet public; first public
releases are in preparation. What you can already find here:

| [drafterino](https://github.com/enhantica/drafterino) | *Releases that draft themselves* — release-notes drafting action |
| [badgery](https://github.com/enhantica/badgery) | *Metrics, beautifully carded* — quality-metric badges and cards |
| [dashboard](https://github.com/enhantica/dashboard) | Published code-quality and CI dashboards for enhantica repositories |
